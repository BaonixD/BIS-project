# Новые возможности BIS Taxi

Реализовано по плану Astra, 16 ноября 2026 года.

## Время поездки

Карточка пассажира показывает расстояние, время и прибытие отдельно для подачи
и движения к месту назначения. Расчёт строится по свежим координатам водителя
через OSRM; при временной недоступности сервиса приблизительная оценка помечается.
Просроченный прогноз не обещает прибытие. Исходное расстояние не уменьшается
по таймеру; в завершённой поездке длительность берётся из времени начала/завершения.

## Документы водителя

Откройте «Профиль → Документы». Нужны два файла: удостоверение личности и права.
PDF — до 10 MiB и 10 страниц, без пароля и активных действий. Обе стороны
удостоверения можно объединить в один файл. Заполните профиль и машину, загрузите
файлы и нажмите «Отправить на проверку».

В админке пакет доступен в карточке водителя: просмотр страниц PDF, масштаб,
скачивание, история версий, возврат с причиной и одобрение с классом машины.
После возврата водитель создаёт исправленную версию и отправляет её снова.
Одобрение адресовано конкретной версии. Изменение существенных данных профиля
сбрасывает допуск; телефон не требует повторного рассмотрения.

Ранее одобренные аккаунты сохранили доступ с явной пометкой о старом допуске;
это не статус проверенных документов. Admin может запросить документы.
Во время принятой поездки изменение пакета запрещено.

Файлы доступны только владельцу и администраторам; не размещаются в public и Git.
`DOCUMENT_STORAGE_DIR` задаёт приватный каталог. Резервная копия включает **базу
и этот каталог**. PDF.js отрисовывает страницы локально, без действий из PDF;
если просмотр недоступен, файл можно скачать под своей сессией.

Очистка файлов без ссылок в БД (только старше суток):

```bash
uv run python scripts/cleanup_documents.py          # только подсчёт
uv run python scripts/cleanup_documents.py --delete
```

Для демонстрации используйте синтетические PDF. Seed создаёт такие документы и
проводит demo-водителей через обычные сервисы подачи/одобрения.

## Достижения

В профилях доступны три значка и прогресс на основе завершённых поездок и оценок.
Старые поездки учитываются. Значки не меняют цену или подбор водителя.
Для высокого рейтинга нужно минимум 5 оценок и среднее не ниже 4,8;
достижение пересчитывается по актуальному рейтингу.

## Поддержка

«Поддержка» доступна из профиля. Из активной поездки и истории можно открыть
обращение с привязкой к поездке. Категории: поездка, оплата, документы, аккаунт,
другое. Сообщения и ответы сохраняются после перезагрузки.

Очередь администратора: `/admin/support`, с поиском, фильтрами и счётчиками
непрочитанного. Admin отвечает и помечает вопрос решённым. Новое сообщение
переоткрывает вопрос. Ответ появляется в приложении; гарантированного времени
ответа, внешних уведомлений и вложений в поддержку в этой версии нет.
Заблокированный аккаунт не может обойти блокировку через поддержку.

Лимиты по умолчанию: 5 новых обращений за 10 минут и 30 сообщений за минуту на
пользователя; конфигурация в `.env.example`. Лимиты живут в процессе и сбрасываются
после рестарта, сами обращения хранятся в SQLite.
