# Отчёты исполнения

Здесь главная сессия Claude сохраняет T00.md–T11.md по мере фактической работы и FINAL.md после T10. Отчёты T00–T10 и FINAL.md записаны по фактическим коммитам и проверкам; вымышленных результатов нет.

Шаблон, статусы и правила возобновления находятся в [TASKS.md](../TASKS.md). Отчёт должен включать SHA, фактическую модель, RED/GREEN, точные команды проверок, результат ревью и внешние ограничения. Секреты и полный вывод окружения не сохранять.
