# S1 — прогноз поездки

Реализовано: отдельный защищённый GET `/api/v1/rides/{ride_id}/estimate`,
дорожный расчёт pickup/dropoff по текущим координатам, 15-секундный bounded cache
с single-flight, помеченный fallback при недоступном провайдере, проверка свежести,
повторная проверка назначения/статуса после HTTP. Кэш принадлежит lifespan приложения.

Frontend: отдельная карточка расстояния, оставшегося времени и прибытия;
polling 15 с только при assigned/in_progress. Истёкшая/недоступная оценка явно
обозначается. Исходное расстояние больше не уменьшается по таймеру.
В завершённой поездке длительность считается из started_at/completed_at,
при отсутствии этих данных используется исходная оценка.
Переводы RU/KK/EN и OpenAPI-типы обновлены.

Проверки: 99 выбранных backend-тестов (estimate, lifecycle, routing wiring),
полный Vitest, TypeScript, ESLint, mypy, Ruff и frontend build.
Изолированные тесты используют FakeRoutingProvider; реальный OSRM этим не подтверждён.

Продолжение S2–S7 завершено. Итоги — в S07.md; черновой архив S2 больше не нужен.
