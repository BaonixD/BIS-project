# S6 — поддержка

Миграция `78463ec05d38`: тикеты, сообщения, монотонные позиции прочтения.
Права владельца/admin, проверка привязки поездки, идемпотентные создание/ответ,
seq-пагинация, ограничения отправки, переоткрытие после ответа и статусы.
Frontend: список, форма, переписка, ранние сообщения, непрочитанные, ссылки из
профилей и поездок, очередь admin. Собственные отправленные сообщения не сдвигают
курсор загрузки вперёд с пропуском входящих. Чтение отмечается по загруженному seq
при видимой переписке у нижнего края. Навигация не перекрывает мобильный ввод.
Сценарий с двумя браузерами прошёл, как и API-проверки прав/дублей/прочтения.
