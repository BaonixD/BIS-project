### Поведение (`modules/payments/`)

- `rules.py`: `PaymentMethod` (cash, kaspi_link), `PaymentStatus` (unpaid, reported, confirmed), `Verification.MANUAL`; `apply_report`, `apply_confirm` (повтор на confirmed → `changed=False`, без второго начисления), `apply_method_change` (после confirmed — 409; на Kaspi без ссылки — 503; Kaspi reported → cash сбрасывает заявление в unpaid).
- `permissions.py`: `PaymentActor`, `authorize_payment_action`: посторонний → 404, участник без права → 403, поездка не завершена → 409. report и смена метода — пассажир поездки; подтверждение cash — назначенный водитель или admin; подтверждение Kaspi — только admin с обязательной заметкой (до 200 символов, без управляющих символов).
- `kaspi.py` и `config.py`: `PaymentSettings` читает `KASPI_PAYMENT_URL`; принимается только `https://pay.kaspi.kz/pay/<id>`, без userinfo, порта, query и fragment; пусто → Kaspi выключен, наличные работают. Значение не попадает в текст ошибок.
- `instructions.py`: сумма из серверного снимка, KZT, метод, статус, `verification: manual`, ссылка только для Kaspi до подтверждения, пометка, что сумму покупатель вводит вручную и открытие ссылки не подтверждает оплату.
- ADR 0004.
