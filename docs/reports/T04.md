### Реализованное поведение

- `modules/rides/pricing.py`: `calculate_fare(distance_m, duration_s) -> Fare` на Decimal, `ROUND_HALF_UP(max(800, 500 + 120·км + 20·мин))`, версия `edu-v1`, KZT; отрицательные, bool, float и None отклоняются.
- `modules/geo/schemas.py`: `Coordinates{longitude, latitude}` со строгими диапазонами, `RouteGeometry` (GeoJSON LineString lon/lat), `RouteResult{distance_m, duration_s, route_geometry, provider}`.
- `modules/geo/config.py`: `RoutingSettings` из `ROUTING_*`; ключ — `SecretStr`, обрезается; по умолчанию 1 повтор и общий срок 10 с (`ROUTING_TOTAL_TIMEOUT_S`).
- `modules/geo/client.py`: `OpenRouteServiceClient` (Directions driving-car GeoJSON) через `httpx.AsyncClient`, протокол `RoutingProvider`.
- Ошибки: `routing_unavailable` 503 без сетевого запроса при отсутствии ключа; `routing_provider_error` 503 с `reason` (`timeout`, `connection_error`, `rate_limited`, `provider_unavailable`, `rejected`, `invalid_response`); `route_not_found` 422 для ORS 2009/2010. Повторяются только timeout, соединение, 429 и 5xx в пределах общего срока.
- `scripts/routing_smoke.py`: opt-in реальный маршрут по Алматы; без ключа — `external_pending`, код 2.
- ADR 0002: выбор провайдера, контракт ошибок, что сверено с документацией ORS и что нет.

### Поведение

- Lifespan создаёт HTTP-клиент и `OpenRouteServiceClient` из `RoutingSettings`, закрывает клиент при остановке; без ключа приложение стартует. `create_app(..., routing_provider=...)` внедряет провайдер (тесты), тогда HTTP-клиент не создаётся.
- `POST /api/v1/geo/route`: любой вошедший пользователь, CSRF; тело `{origin, destination}`; ответ `RouteResult` без цены. Совпадающие точки — `422 route_points_identical` без запроса к провайдеру. Ошибки адаптера — в едином конверте. Во время внешнего запроса соединение с БД не удерживается (тест через `engine.pool.checkedout()`).
- `Coordinates` теперь `extra="forbid"`.
- Контракт для T05: `RoutingProviderDep`, `plan_road_route(provider, origin, destination)` вне транзакции; `tests/support/routing.py`: `FakeRoutingProvider`, `fake_route` (10 000 м / 1500 с → 2200 KZT), `isolate_routing_environment`.
