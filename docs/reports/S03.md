# S3 — решение администратора

Старый approve проверяет конкретный отправленный пакет и profile_revision.
У новых водителей обойти пакет запросом без тела нельзя. Возврат содержит причину,
ревизия отзывает допуск, изменение профиля создаёт новую версию. Активная поездка
защищена от изменений. Legacy-доступ сохранён только ранее approved водителям;
новые demo-аккаунты проходят нормальную подачу синтетических PDF.
Очередь фильтруется по документам; счётчики новых проверок считают pending-пакеты.
