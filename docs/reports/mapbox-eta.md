# Mapbox ETA — реализация и включение

16 ноября 2026. План: [mapbox-eta](../plans/mapbox-eta.md).

## Результат

MapboxClient Directions v5 driving-traffic + OSRM fallback; прежний ORS доступен.
Одна геометрия, расстояние и длительность; duration_typical не используется для
основного ETA. Явный traffic_mode, метаданные сохраняются quote→ride. JSON-колонка
обоснована сохранением прогноза в истории; старым данным трафик не приписан.
Кэш 30 с/256 маршрутов с объединением запросов; таймауты, retry 429/5xx, NoRoute
без fallback, 401/403 без retry. Бюджет резервного OSRM — 3 с.
Токен только в .env, не в ответах и обычных HTTPX-логах.

Плашка остаётся на карте, RU/KK/EN; изменяется пояснение дорожных условий.
Quote старше минуты/истёкший обновляется перед заказом с повторным подтверждением.
Цена уже созданного заказа не меняется при обновлении ETA. Активная карта и
показатели читают один общий estimate с геометрией, опрос раз в 60 с.
