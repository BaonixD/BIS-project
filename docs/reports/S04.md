# S4 — документы в интерфейсе

Добавлены checklist и два слота PDF в кабинете водителя, submit/revise и ошибки.
Admin видит пакет рядом с данными водителя, открывает PDF, возвращает с причиной
или одобряет актуальную версию. PDF.js загружается по запросу, имеет страницы,
масштаб и защищённое скачивание. На телефоне карточки стоят колонкой, на широком
экране данные и документы размещены рядом. Проверен реальный browser flow.
