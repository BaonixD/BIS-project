# S2 — хранение и версии PDF

Приватные файлы, метаданные и версии пакетов, ограничение multipart до разбора,
чтение частями, SHA256, случайные ключи, права файла, PDF-парсер в отдельном
процессе с CPU/временным пределом. Некорректные, активные и зашифрованные PDF
отклоняются. При rollback новый файл удаляется; есть dry-run очистка orphan-файлов.
Миграция `bdcfcb98a096`; тесты выполнены в конце, см. S07.
