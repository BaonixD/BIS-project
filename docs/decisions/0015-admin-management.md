# ADR 0015 — Управление доступом и рабочие списки администратора

Дата: 9 ноября 2026. По запросу владельца расширена админка: управление
пользователями, контроль водителей и поездок, показатели сервиса.

## Решение

- В `users` добавлены nullable `blocked_at`, `block_reason`, `blocked_by`
  (UUID инициатора). Миграция `c6f8a4d219e0` сохраняет существующие аккаунты активными.
- `PUT /api/v1/admin/users/{id}/access` блокирует или разблокирует аккаунт.
  Нужны сессия администратора и CSRF. Для блокировки обязательна причина (3–500 символов).
- Аккаунты администраторов защищены от блокировки, включая собственный аккаунт.
  Блокировка запрещена при активной поездке участника и при неполученных наличных
  по завершённой поездке водителя. Администратор не меняет статусы поездок произвольно.
- Блокировка, отзыв сессий, снятие водителя с линии и отзыв ожидающих предложений
  выполняются в одной транзакции. Проверки входа по паролю и Google запрещают
  выдачу сессии заблокированному аккаунту; проверка действующей сессии также
  учитывает блокировку. Разблокировка не восстанавливает старые сессии и доступность.
- Поиск и фильтрация выполняются до пагинации; `total` соответствует фильтрам.
  Символы `%` и `_` ищутся буквально, SQLite использует Unicode casefold.
  PostgreSQL компилирует поиск через `lower`; реальное подключение PostgreSQL не проверялось.
- Административная выдача поездок дополнена именами участников, получаемыми в том же
  запросе списка. Публичная история пассажира и водителя сохраняет прежний контракт.
- `GET /api/v1/admin/overview` возвращает показатели за всё время. Оплата учитывает
  только завершённые поездки: отдельно `paid` и ожидаемые наличные. Kaspi остаётся имитацией.

## Последствия

Администратор может искать по всей базе, переходить по страницам и открывать
карточки напрямую, без загрузки первых 100 пользователей. Нужна новая миграция
перед перезапуском API; генерация типов frontend выполняется из обновлённого OpenAPI.
Текущие данные блокировки очищаются при разблокировке; отдельного журнала
административных действий пока нет.
