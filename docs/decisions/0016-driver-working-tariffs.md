# ADR 0016 — Класс автомобиля и тарифы смены

Дата: 9 ноября 2026. Уточнение владельца: машина автоматически допущена к своему
классу и тарифам ниже; водитель выбирает рабочие тарифы при выходе на линию.
Дополняет [ADR 0012](0012-tariffs-and-car-classes.md).

## Решение

- Администратор по-прежнему задаёт один максимальный `car_class`.
  `economy` открывает один тариф, `comfort` — два, `comfort_plus` — три,
  `business` — все четыре. Поле `vehicle.categories` возвращает этот вычисленный допуск.
- `DriverResponse.enabled_categories` — сохранённый выбор водителя, отдельный от допуска.
  Он хранится в `vehicle_categories(vehicle_id, tariff)` с составным первичным ключом,
  CHECK допустимых тарифов и FK к автомобилю с каскадным удалением.
- `PUT /drivers/me/availability` принимает `{online: true, categories: [...]}`.
  Выбор должен содержать 1–4 разных разрешённых тарифа. Тариф выше класса,
  пустой список, дубликаты, неизвестные значения и явный `null` отклоняются (`422`).
  Изменять категории могут только сам водитель с действующим допуском и CSRF.
- Для совместимости запрос `{online: true}` сохраняет прежний выбор.
  `{online: false}` снимает с линии, не сбрасывая предпочтения.
  Передавать категории при `online: false` нельзя.
- Dispatch проверяет одновременно максимальный класс и наличие выбранного тарифа
  в `vehicle_categories`. Изменение выбора отзывает только ожидающие предложения
  исключённых тарифов; принятые поездки продолжаются.
- При смене класса выбор «все» остаётся выбором всех новых доступных тарифов.
  Явные исключения водителя сохраняются с ограничением по новому классу.
  Если пересечение пустое, водитель снимается с линии и получает допустимый набор
  для следующего выхода; новый набор проверяется в интерфейсе перед подтверждением.
- Интерфейс показывает чекбоксы доступных тарифов перед выходом на линию и кнопку
  «Изменить тарифы» при ожидании заказа. Пустой набор не позволяет подтвердить выход;
  ошибка сервера оставляет окно открытым. Модальное окно поддерживает клавиатуру
  и управление фокусом через существующий Radix Dialog.

## Миграция

`a3267d91e0b4` создаёт таблицу и заполняет все ранее разрешённые тарифы существующих
автомобилей: бизнес получает четыре записи, комфорт — две и т.д. Действующие допуски
и возможность принимать прежние заказы сохраняются. Откат удаляет настройки смены;
повторное обновление начинает с полного допуска машины.

Категории загружаются одним select-in запросом на всю страницу автомобилей,
без дополнительных запросов на каждого водителя. Миграция проверяется на данных,
с откатом, повторным обновлением и Alembic schema diff.
